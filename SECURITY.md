# Seguridad

Si encontrás una vulnerabilidad en la skill (por ejemplo, una forma de que el contenido de un repo revisado haga que los agentes se salten sus reglas), **no abras un issue público**. Usá [«Report a vulnerability»](https://github.com/grupovimo/comite/security/advisories/new) en la pestaña Security de este repo.

Contestamos en lo que da el tiempo; no hay recompensas.

Recordatorio: las reglas que reciben los agentes son instrucciones, no un aislamiento. El README, en «Datos, seguridad y límites», explica cómo correr el comité sobre código que no es tuyo.
